# Licenses

Licenses and notices for the third-party work shipped with spruceOS.
spruceOS itself is covered by the `LICENSE` file in the repository root.

| Folder | Covers |
|---|---|
| top level | standalone emulators and apps, kernel modules |
| `cores/` | libretro cores, one file per core |
| `tools/` | command-line tools and services in `spruce/bin`, `spruce/bin64` and elsewhere |
| `libraries/` | shared libraries bundled with emulators, apps and the system layer |
| `fonts/` | fonts |
| `assets/` | RetroArch assets, shaders, controller databases, arcade data files |
| `vendor/` | proprietary binaries from device makers |
| named folders | components that ship several license files of their own |
