Brick Game developed by Dan Shimmyo:

Brick Game is a classic arcade-style brick breaker game and a love letter to early video games from the 1970s. It is designed for fast-paced action and can be paired with an analog paddle controller for an authentic nostalgic experience. Originally developed for the GameTank 8-bit console, this release is by the authors permission for distribution by spruceOS. Thanks Dan!
