# Translations

Cheevos shows itself in the language chosen in Spruce's settings when this folder has a
translation for it. A translation is `<Language>.json`, named exactly as Spruce's own file for
the language in `App/PyUI/lang/`: `Ukrainian.json`, `Chinese (S).json`.

Send new translations and fixes to https://github.com/spruceUI/cheevos, not to SpruceOS. Each
Cheevos release replaces `App/Cheevos/` in Spruce, so a change made there is lost.

How to start a translation, what the file holds and how to check it:
https://github.com/spruceUI/cheevos/blob/master/CONTRIBUTING.md#translating
